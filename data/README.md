# Data directory

- `india_ecommerce_market.csv`: published market benchmark values; forecasts are labelled.
- `survey_template.csv`: blank schema for primary survey responses (14 fields).
- `sample_survey_responses.csv`: **60 illustrative SYNTHETIC responses** used to demonstrate the clustering pipeline reproducibly. Generated by `scripts/make_sample_survey.py` (fixed seed 20241120) with three planted behavioural patterns. Not real survey data; do not report as field findings.
- `survey_responses.csv`: optional local file of consented, anonymised **real** responses; git-ignored. When present, `run_project.py` uses it in preference to the sample.
- `transactions.csv`: optional permitted Indian transaction extract; git-ignored.

## Survey encoding used by the clustering pipeline

`segmentation.py` converts the questionnaire's ordinal text answers to numbers before scaling:

| Column | Question | Mapping |
|--------|----------|---------|
| `price_sensitivity` | Q9 | Not at all 1, Slightly 2, Moderately 3, Very 4, Extremely 5 |
| `discount_importance` | Q10 | Numeric 1–5 |
| `emi_influence` | Q11 | Not at all 1, A little 2, Somewhat 3, A lot 4; "Not eligible / Unsure" = missing |
| `exchange_influence` | Q12 | Not at all 1, A little 2, Somewhat 3, A lot 4; "Not applicable" = missing |
| `delivery_cost_influence` | Q13 | Not at all 1, A little 2, Somewhat 3, A lot 4 |

Rows with any missing influence score are excluded from clustering (reported in `outputs/segment_validation.csv`). "Not applicable" is never treated as a low score.

Recommended transaction columns: order_id, customer_id, order_date, category, product, quantity, unit_price_inr, discount_inr, state. Use ISO dates and anonymised customer IDs. Document data owner, period, sampling frame, licence and cleaning rules.
