# CNT-02 — India E-Commerce Market Growth and Consumer Segmentation

This folder contains the reproducible Python analysis. Run `pip install -r requirements.txt` once, then `python run_project.py`. The script generates PNG charts, CSV tables and an HTML report under `reports/`. It runs offline after dependencies are installed.

The committed SVG charts in `reports/figures/` are preview versions of the same market analysis. No fabricated survey or transaction observations are used. An order-value histogram and customer clusters are intentionally omitted until real transaction/survey data is supplied.
